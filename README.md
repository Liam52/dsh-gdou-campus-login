广东海洋大学校园网（深澜 / srun 认证）自动登录插件，以 **DeepSeek Harness（DSH）** 的 bundle 插件形式运行。

断网后自动重新认证，直到恢复联网；同时在 DSH 左侧边栏提供「校园网」面板，账号、设置、公告缓存全部留在本机。插件还会向智能体注册 `campus_net` 工具，可以直接用一句话查询状态或登录。

> 非官方项目：与广东海洋大学、深澜网络均无隶属关系。仅供学习交流，使用风险自负。

## 功能

**联网**

- 断网自动认证：TCP 探测失败即重新登录，离线时持续重试直到恢复
- 实时联网状态，检测间隔可配置（默认 1 秒）
- 账号密码在面板内填写，支持多账号快速切换
- 上网协议勾选同意（学校要求，未同意时认证会被拒绝）
- 手动登录 / 登出 / 重新检测

**信息**

- 流量用量：累计总用量、累计时长、在线设备数
- 网络测速：微软 / 腾讯云 / Cloudflare / 华为云 / 阿里云五个源，8 条并发连接累加
- 选课公告：抓取教务部通知，自动识别开始 / 截止时间并倒计时

**可靠性**

- 校园网环境检测：不在校园网时不做无谓的认证尝试
- 错误分类：密码错误立即停止重试，避免触发风控；限流自动长退避
- 一键诊断：网关、门户、认证接口、协议、ac_id、账号逐项检查
- 运行日志：最近 120 条，面板内可查

**外观**

- 默认海洋蓝图背景（校色网格 + 海风渐变），可切换点阵 / 纯色 / 关闭
- 卡片入场、海浪浮动、状态呼吸等动效，尊重系统「减少动态效果」设置
- DSH 主题 token 缺失时自动回退，浅色 / 深色都能正常显示

## 界面

侧边栏「校园网」进入主面板，自上而下是四块：

| 区块 | 内容 |
| --- | --- |
| 状态与流量 | 顶部状态徽标、累计总用量、累计时长、在线设备数、刷新 |
| 选课公告 | 通知标题、开始 / 截止时间与倒计时、手动刷新 |
| 网络测速 | 选择测速源后开始，显示下行速率与耗时 |
| 快捷操作 | 立即登录 / 登出 / 重新检测 |

右上角「设置」里可以管理账号、上网协议、ac_id、界面背景、检测间隔、断网自动认证，以及进入「诊断」页。

同时向智能体提供以下工具：

| 工具 | 说明 |
| --- | --- |
| `campus_net` | `status` 查看状态 / `login` 立即登录 / `logout` 登出 |

## 环境要求

- 已安装 DeepSeek Harness（DSH）0.2.x
- Node.js 20 及以上
- 处于广东海洋大学校园网环境（有线或无线均可）

## 安装

插件以 bundle 形式发布：先拿到源码，把路径交给 `plugin_manager` 的 `install_bundle`，再重启 DSH 生效。

```bash
git clone https://github.com/Liam52/dsh-gdou-campus-login.git
cd dsh-gdou-campus-login
```

**方式一：安装源码目录**

```text
把本仓库目录的路径交给 plugin_manager 的 install_bundle
```

**方式二：打包成 tgz 再装**（方便分发给同学）

```bash
npm pack          # 生成 local-gdou-campus-login-1.1.1.tgz
```

```text
把 tgz 的本地路径交给 plugin_manager 的 install_bundle
```

Releases 页面也会附带由 tag 自动构建的 tgz。

安装完成后重启 DSH，左侧边栏会出现「校园网」图标。

> 安装只是把插件装进当前 profile，不会覆盖你的账号数据；数据位置见[数据与隐私](#数据与隐私)。

## 首次使用

1. 打开侧边栏「校园网」→ 点右上角「设置」
2. 填写学号与校园网密码，点「保存并切换」
3. 在「上网协议」里勾选同意（不勾选无法登录）
4. 回到主界面点「立即登录」验证

成功一次之后保持「断网自动认证」开启即可，之后断网会自动恢复。

## 工作原理

1. **联网判定**：周期性对 `baidu.com:80` 做 TCP 探测，失败视为断网（可在设置里调间隔）
2. **环境判定**：确认本机确实在校园网内，避免在宿舍外做无谓尝试
3. **取 challenge**：向 `http://10.129.1.1/cgi-bin/get_challenge` 请求 `token` 与本机 IP（带 IP 请求才能拿到后续可用的 token）
4. **计算校验**：按深澜协议做 HMAC-MD5（`hmd5`）、XEncode（`info`）与 `chksum`，再 POST `srun_portal`
5. **结果分类**：`ok` / 密码错误 / 限流 / `ac_id` 失效 / 协议未同意，分别处理
6. **记住现场**：登录成功的 `ac_id` 会记住，下次优先复用

协议部分依据公开的反向资料重写实现，仓库内不打包任何第三方二进制或闭源组件。

## 关于 ac_id

`ac_id` 标识当前接入设备，会随位置（教学楼、宿舍、无线 AP）变化。插件按可信度依次尝试：

1. 断网劫持跳转里的 `ac_id`（未认证时请求外网被门户劫持，最可信）
2. 手动填写的 `ac_id`
3. 上次登录成功的值
4. 门户根路径给的值（多为默认值，仅参考）
5. 配置值（默认 25）
6. 已知有效列表，最多再试 6 个

成功一次即记住。设置页可以查看当前 `ac_id` 的来源，也可以手动覆盖（留空表示始终自动获取）。

## 选课公告

每次**登录成功后**抓取一次，另外**每天中午 12:00** 抓取一次，面板上也可手动刷新；启动时若缓存超过一天会补抓一次。

抓取结果缓存在本地，重启后立即可见。时间段由正文自动识别（例如「第一轮：2026年11月5日14:30－11月9日10:00」），**仅供参考，请以教务部原文为准**。

公告来源与关键字都写在默认配置里，学校调整栏目结构后可能需要更新 `noticeUrl` 与 `noticeKeywords`。

## 数据与隐私

账号、设置、公告缓存都保存在本机，不上传任何服务器：

- 有 profile 时：`%DSH_PROFILE_DIR%\gdou-campus-login\`
- 否则：`~/.dsh/gdou-campus-login/`

| 文件 | 内容 |
| --- | --- |
| `account.json` | 多账号列表，**密码为明文**，文件权限 0600 |
| `settings.json` | 检测间隔、自动认证、背景样式等 |
| `notices.json` | 选课公告缓存 |

插件只在认证时把账号密码发往校园网门户（`10.129.1.1`）本身，不经过任何第三方。**请勿分享上述目录，也不要把它提交进 git。**

提交 issue 或贴日志前，请先删掉学号、密码、IP。

## 常见问题

**登录失败，提示密码错误**

面板会暂停自动重试，避免连续失败触发风控。改对密码或重新点「立即登录」后恢复。

**提示限流 / 频繁认证**

插件会自动长退避。若手动反复点击，可能延长冷却时间，建议等几分钟。

**提示设备数已达上限**

学校限制在线设备数时，需要先在其它设备退出校园网，再登录。

**断网后没有自动登录**

- 确认「断网自动认证」是开着的
- 确认当前不在校园网外（环境检测会主动跳过）
- 点「一键诊断」，逐项看网关、门户、认证接口、协议、ac_id、账号

**面板没有出现**

插件装好后需要重启 DSH。仍不出现时检查 `plugin_manager` 里插件是否启用。

## 已知限制

- 仅适配广东海洋大学当前门户（`10.129.1.1`，深澜 V1.18），换学校需要改默认配置
- 学校若更换认证协议或页面结构，需要同步更新
- 部分高校测速站只允许本校网络访问，校外不可用
- 公告时间由正则识别，格式变化时可能识别不到（届时显示原文链接）

## 开发

- **无构建步骤**：`client.js` 直接通过 `__ModuleLoader__` 注册，改完重启 DSH 即可
- **无运行时依赖**：只用 Node 内置模块与 DSH 提供的 React
- **语法检查**：

```bash
node --check index.js
node --check client.js
```

改完把目录重新安装一次（或打 tgz 后安装）再重启 DSH 验证。

欢迎提交 issue / PR。涉及认证协议的改动请说明测试环境（位置、`ac_id` 来源、门户外网可达性）。
